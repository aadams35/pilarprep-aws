# Approved AWS reference excerpts

Use these short approved principles as architecture evidence, not as customer facts.

- AWS Well-Architected guidance favors explicit business outcomes, evidence-based risk review, and trade-off decisions across the six pillars.
- Event-driven integration should define idempotency, failure handling, retries, observability, and ownership.
- Sensitive workloads should apply least privilege, encryption, traceable change control, and data-retention decisions.
- Reliability claims should be supported by recovery objectives and tested recovery procedures.
- Managed services are recommendations only when their capabilities and constraints fit the confirmed requirement.
